# Reel Insights: TMDB Movie Industry Analytics

## Project Overview
Reel Insights is an end-to-end data analytics project exploring the global movie industry using a relational dataset of ~2,500 movies from The Movie Database (TMDB).

## Repository Layout
- `01_data_cleaning.ipynb`: Data wrangling, type cleaning, orphaned row removal, and SQLite database setup.
- `02_sql_analysis.ipynb`: Execution and commentary for all 10 SQL queries.
- `03_pandas_analysis.ipynb`: Execution and commentary for all 10 Pandas EDA questions.
- `04_visualizations.ipynb`: 12 Univariate, Bivariate, and Multivariate charts with insights.
- `app.py`: Multi-page interactive Streamlit dashboard.
- `README.md`: Project overview and executive recommendations.
- `requirements.txt`: Python package requirements.

## Top 5 Business Insights
1. Genre Hybridization Drives Mega-Blockbusters: Top grossing films blend Action, Adventure, Sci-Fi, and Fantasy.
2. Animation & Family Offer High Capital Efficiency: High ROI and strong catalog retention.
3. Budget Discipline Prevents Box Office Failures: Uncontrolled spending without audience targeting leads to losses.
4. Director Brand Equity Creates Consistent Value: Veteran directors drive disproportionate long-term returns.
5. Popularity Metrics Require Engagement Verification: Pairing popularity with vote count gives accurate audience intent.
